# Release checklist – website

Nothing is published while an item is open.

## Content
- [ ] Company details in `index.html` and `privacy.html` match the extract from the Commercial Register (name, Company ID, registered office, court and file number)
- [ ] Contact e-mail works (send a test message)
- [ ] "Last updated" date in `privacy.html`
- [ ] Privacy policy reviewed (it is a draft written without a lawyer)
- [ ] `scripts/test.ps1` passes (no PLACEHOLDER left)

## Look
- [ ] Checked on a phone and a computer, in light and dark mode

## Hosting (once)
- [ ] Public repository on GitHub, Pages from `main` / root
- [ ] Custom domain set, DNS records in place, **Enforce HTTPS** ticked
- [ ] Domain verified in the GitHub account or organization
- [ ] Domain set to renew automatically
